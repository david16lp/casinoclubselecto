🎰 Casino Club Selecto

Proyecto académico desarrollado para el módulo de Proyecto Intermodular (DAM/DAW).

📖 Sobre el proyecto

Casino Club Selecto es una plataforma de entretenimiento (Web y App móvil) que integra juegos de casino y apuestas deportivas eSports utilizando exclusivamente saldo virtual (dinero ficticio). El proyecto destaca por ofrecer:

- Transparencia: Juegos verificables matemáticamente mediante hash (SHA-256).
- Juego Responsable: Límites de gasto obligatorios y configurables por el usuario.
- Monedero unificado: Saldo compartido entre la aplicación web y la aplicación Android.

🛠️ Stack Tecnológico
- Backend: Java (Spring Boot)
- Frontend Web: Angular
- App Móvil: Android (Kotlin)
- Base de Datos: PostgreSQL
